# Stage 1 模型原理

**混合整數線性規劃 (MILP)**：在單一再平衡時點,求最大化投資吸引力、且符合多重風險限制的理想連續權重。所有看似非線性的部分都已線性化,CBC / Gurobi 可直接求解。

符號：`i` 股票、`j` 產業、`s` 情境、`Ω` 情境集合。

## 變數
`w_i ≥ 0` 權重、`z_i ∈ {0,1}` 是否持有、`δ⁺_i, δ⁻_i ≥ 0` 周轉調整、`η, ξ_s` CVaR 輔助變數。

## 目標
`max Σ μ_i w_i`(μ_i = 投資吸引力分數,預設 12-1 月動能)

## 限制
| # | 限制 | 式子 |
|---|---|---|
| 1 | 預算 | Σ w_i = 1 |
| 2 | 持股檔數 | Σ z_i = K |
| 3 | 權重上下限 | L_i z_i ≤ w_i ≤ U_i z_i |
| 4 | 產業集中度 | Σ_{i∈S_j} w_i ≤ γ_j |
| 5 | Beta | Σ β_i w_i ≤ β^max |
| 6 | 流動性 | w_i ≤ ℓ_i |
| 7 | 周轉率 | w_i−w_i⁰ = δ⁺_i−δ⁻_i,Σ(δ⁺_i+δ⁻_i) ≤ τ |
| 8 | CVaR 下檔風險 | ξ_s ≥ −Σ r_{i,s} w_i − η,η + (1/((1−α)\|Ω\|))Σ ξ_s ≤ C̄^risk |

L_i / U_i 是 **per-stock**(與 Stage 2 整數張數可行域對齊,見 [detail.md](detail.md))。

## 線性化技巧
| 看似非線性 | 線性化方式 |
|---|---|
| CVaR | Rockafellar–Uryasev:引入 η, ξ_s |
| 周轉率 \|w−w⁰\| | 拆成 δ⁺−δ⁻ |
| 選股 + 上下限 | z_i∈{0,1},L z ≤ w ≤ U z |

## 自創啟發式(對照最佳解用)

不呼叫 solver,純啟發式逼近最佳解(`heuristic.py`):

- **Top-K 基準(下界)**：依 μ 取前 K 名 → water-fill 配權 → 修復至可行。**選股不最佳化**,故為弱基準。
- **自創 heuristic**：多起點(μ-貪婪 + Top-K)→ 限制修復(用組合風險分數搬權重,搬不動就換股)→ 1-swap 局部搜尋。其中一個起點即 Top-K 解,局部搜尋只接受「可行且更好」的換股,因此 **保證 ≥ Top-K**。

`benchmark.py` 把「Top-K < heuristic ≤ 最佳解」三者的目標值、optimality gap、求解時間列表對照(作業 §5.6)。
